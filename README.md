# Course Catalog

Interview exercise: a UI for registering, logging in, and browsing courses.

Accounts and course data come from the [course API](https://github.com/LifeAyush/course-api).

## How to run

```bash
git clone https://github.com/LifeAyush/course-catalog.git
cd course-catalog
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000). The UI calls the API at `http://localhost:1337`.
